# VoiceSmith 0.5.0

本次是首个 0.x 里程碑版本：界面按 SVC Studio 的结构重构（保留原蓝色配色），长任务改为后台任务队列，训练支持停止后从检查点继续。

## 新增与改进
- 界面重构：图标侧边栏 + 5 步产线条（项目 → 数据集 → 预处理 → 训练 → 推理）+ 统一页头，保留原来的蓝色主题。
- 预处理：点击「开始预处理」创建后台任务，按顺序排队执行；切换页面不会中断，可在「任务」页查看进度或取消。
- 训练：单按钮「开始训练 / 停止训练 / 继续训练」；继续时加载最近检查点，保留之前的训练权重与优化器状态，不会从头训练。
- 训练参数说明：S1/S2 epochs、batch、DataLoader 进程数、强制训练都加了内联解释。
- 安装更新时自动清理旧运行时目录，保留 data（模型资产、数据集、音色、训练记录）。
