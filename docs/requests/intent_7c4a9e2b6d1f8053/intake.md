# Intake · GPT-SoVITS 桌面 TTS 工坊

## 1. 产品形态

Windows 桌面应用：Tauri 2（Rust + WebView2）+ Vue 3 + TypeScript + Python sidecar。
模型、推理、训练、数据全部本地；零服务器成本；默认零遥测。

## 2. 目标用户

- 个人创作者：6–12GB GPU，短视频/口播/有声内容。
- 小型工作室：12–24GB GPU，批量配音、参数预设。
- 声音所有者：本地训练私有音色，数据不出机。

## 3. 引擎

- GPT-SoVITS（MIT），锁定 commit。
- 训练复用 `prepare_datasets` + S1/S2；推理复用 `GPT_SoVITS.TTS_infer_pack.TTS`。
- 模型版本 V2/V2Pro/V2ProPlus/V3/V4/V5；默认 V2Pro；采样率以 config 为准。
- 情绪只走参考音频；官方 README 仍将“增强情感控制”列为未完成。

## 4. 硬件基线

- 6GB 显存：推理；12GB 起：训练；CPU 仅推理兜底。
- Windows 10 22H2 / 11 x64；NVIDIA 驱动 535+；安装后预留 20GB。

## 5. 范围

In：安装器、doctor、模型资产、零样本/微调、单条/批量推理、参考音频情绪、导出、历史、任务中心、本地数据、零遥测。

Out：云端服务、账号、配额、计费、abuse 运营、SVC、实时对话 TTS、移动端/macOS/Linux 首发、公开分享/社区、内容审核/名人声纹/授权审核。

## 6. 十条 P0 用户旅程

| ID | 旅程 | 成功判据 |
|---|---|---|
| J1 | 安装 → 首启 → doctor | 8 项全绿或给出可复制修复命令 |
| J2 | 断网导入模型 | 校验通过，可用 |
| J3 | 50 字试听 | 30 秒内听到音频 |
| J4 | 8 秒参考创建快速音色 | 不训练可合成，可删除 |

## 7. 成功指标

安装成功率 ≥98%；首音频 ≤10 分钟；6GB 10s RTF ≤2.0；100 步冒烟 ≤10 分钟；UI P95 <200ms；24h 无崩溃；遥测 0；卸载残留 0。
