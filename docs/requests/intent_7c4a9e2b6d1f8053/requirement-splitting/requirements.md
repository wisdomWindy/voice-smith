# 需求拆分（M0/M1 基线）

> 来源：`PRD.md` v3.0。P0 = 首次公开内测必须；P1 = V1。

| ID | 需求 | P0 验收 |
|---|---|---|
| FR-01 | 环境自检与修复 | doctor 八项 pass/fail/修复命令 |
| FR-02 | 模型资产中心 | 离线导入、sha256、修复 |
| FR-03 | 文本编辑与试听 | ≤50 字 30s 内返回 |
| FR-04 | 快速音色（零样本） | 8s 参考可合成、可删除 |
| FR-05 | 精细音色训练 | 100 步冒烟、断点续训、取消 5s |
| FR-06 | 参考音频情绪 | 未绑定返回 `emotion_effective=false` |
| FR-07 | 推理参数与预设 | 参数透传、越界裁剪 |
| FR-08 | 单条与批量推理 | 批量失败隔离、可重跑 |
| FR-09 | 历史、导出与删除 | 原生采样率、删除无残留 |
| FR-10 | 任务中心与错误码 | 12 类错误可读 |
| FR-11 | 本地数据与隐私 | 零遥测、删除传播 |
| FR-12 | 打包、安装与卸载 | 干净机、离线、卸载无残留 |

## 非功能

- 6GB 10s RTF ≤2.0；UI P95 <200ms；24h 无崩溃。
- 安装包 ≤3.0GB（不含模型）；UI ≤3s；引擎 ≤10s。
- 默认离线、零遥测；中文路径可用。

## P1

- AI 预置音色 BYO Key；音色对比 ≤3；批量预设；多语言；CPU 优化。
