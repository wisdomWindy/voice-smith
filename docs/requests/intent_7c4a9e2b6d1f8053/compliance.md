# 合规与边界

## 1. 许可证

- GPT-SoVITS 代码 MIT；安装包保留 `LICENSE` 与版权声明。
- Tauri（MIT/Apache-2.0）、Vue（MIT）、Python 依赖按各自许可证列入 SBOM。
- 模型权重不内置；资产页展示来源与许可提示，用户自担授权。

## 2. 使用规约

首次启动展示一页规约：

- 用户对输出用途负责；
- 禁止伪造他人声音、诈骗、违法内容；
- 平台不做内容审核，也不对输出用途背书。

## 3. 隐私

- 默认零遥测；更新检查默认关闭。
- 音频、模型、参考音频、日志仅本地。
- 删除音色/账户数据时清理 SQLite、模型、参考音频、缓存。

## 4. 不做的范围

- 内容审核系统；
- 名人声纹库；
- 训练授权审核；
- 公开分享/发现/排行榜；
- 云端账号/配额/计费。

## 5. 发布材料

- 安装包 sha256；
- SBOM；
- 第三方许可证清单；
- 模型资产来源说明；
- 回滚包。
