# M0 验证记录

日期：2026-11-18  
环境：Windows 11 x64；Node 26.13；pnpm 11.28；Rust 1.98；Python 3.11.16（uv venv）；RTX 5060 Ti 16GB。

## 1. 前端构建

命令：`pnpm build`  
结果：通过。Vite 输出 `dist/`，`vue-tsc --noEmit` 无错误。

## 2. Rust / Tauri 构建

命令：`cargo check`（src-tauri）  
结果：通过。

命令：`pnpm tauri build --debug --no-bundle`  
结果：通过；生成 `src-tauri/target/debug/voice-smith.exe`。

## 3. Sidecar API

命令：`sidecar/.venv/Scripts/python.exe sidecar/app.py --port 8765 --token dev-token --data-dir .data`

## 4. 桌面端到端

启动 `voice-smith.exe`：

- 窗口标题：`VoiceSmith · GPT-SoVITS 桌面工坊`；
- 引擎状态 `ready`，sidecar 日志显示随机端口（本次 5020）与 health/voices 请求；
- 点击“试听 50 字”出现音频播放器；
- 点击“提交合成”：`queued → succeeded`，出现下载 WAV；
- 打开“环境自检”并运行 doctor：Python/GPU/ffmpeg/磁盘 pass，
